# Contributing

Thank you for your interest in improving this project.

1. Open an issue describing the proposed change.
2. Keep changes focused and avoid committing generated files, credentials, personal data, or local runtime state.
3. Add or update tests and documentation when behavior changes.
4. Run the project validation commands documented in the README.
5. Submit a pull request with a concise description of the change and its risks.

By contributing, you agree that your contribution may be distributed under this repository’s license.
